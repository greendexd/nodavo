Nodavo is currently a documentation-first pre-alpha project. These documents define what must be proven before implementation claims become product claims.

- [Roadmap](roadmap.md) — Now, Next, and Later without artificial dates.
- [Privacy](privacy.md) — local-first data handling and telemetry rules.

## Engineering

- [Architecture](architecture.md) — processes, crates, platform boundaries, and data paths.
- [Security model](security-model.md) — threats, pairing, trust, input, clipboard, files, and updates.
- [Clean-room policy](clean-room-policy.md) — rules preventing incompatible source reuse.
- [Technical glossary](glossary.md) — consistent English/Russian terms used by the project.
- [Building](building.md) — current development prerequisites and build commands.
