# Технический глоссарий

[English](glossary.md) · [Русский](glossary.ru.md)

Глоссарий сохраняет единообразный язык в английской и русской документации. Названия протоколов, API операционных систем и общепринятых инженерных артефактов не переводятся, когда это упрощает поиск в первичной документации.

| Термин | Значение в Nodavo |
| --- | --- |
| Программный KVM | Программа, которая позволяет использовать клавиатуру, указатель и выбранные данные на нескольких компьютерах без аппаратного KVM-переключателя. |
| Локальная работа | Основной обмен происходит между сопряжёнными устройствами в локальной сети и не требует облачного сервиса. |
| Узел (peer) | Сопряжённое устройство Nodavo с собственным постоянным идентификатором. |
| Сопряжение (pairing) | Подтверждаемое пользователем установление доверия между двумя устройствами. |
| Разрешение возможности | Отдельное разрешение на удалённый ввод, буфер обмена или файлы. |
| Аренда фокуса | Кратковременное исключительное право направлять удалённый ввод. |
| Проверочный эксперимент | Небольшой одноразовый опыт, подтверждающий или опровергающий рискованное предположение о платформе. |
| Чистая реализация | Оригинальный код, созданный по документированному поведению и публичным спецификациям, без копирования чужой реализации. |
| Датаграмма QUIC | Ненадёжное сообщение QUIC с малой задержкой для заменяемых событий движения указателя. |
| Надёжный поток | Упорядоченный канал QUIC для данных, потеря которых оставила бы неверное состояние. |
| SBOM | Перечень компонентов и зависимостей, вошедших в релиз. |
| Происхождение сборки (provenance) | Проверяемая связь артефакта релиза с исходным кодом и процессом сборки. |
