# Architecture Decision Records

ADRs record decisions that are accepted and expected to remain relevant. Proposed work belongs in issues or the product plan.

Use sequential names such as `0001-transport-quic.md` and include:

- status;
- context;
- decision;
- alternatives;
- security and privacy impact;
- consequences;
- references and provenance.
