# Technical glossary

[English](glossary.md) · [Русский](glossary.ru.md)

This glossary keeps product language consistent across English and Russian documentation. Names of protocols, operating-system APIs, and established development artifacts remain untranslated when that makes them easier to search in upstream documentation.

| Term | Meaning in Nodavo |
| --- | --- |
| Software KVM | Software that shares keyboard, pointer, and selected data between computers without a hardware KVM switch. |
| Local first | Core operation stays between paired devices on the local network and does not require a cloud service. |
| Peer | A paired Nodavo device with its own persistent identity. |
| Pairing | User-confirmed establishment of trust between two devices. |
| Capability grant | Separate permission for remote input, clipboard, or files. |
| Focus lease | Short-lived exclusive ownership of remote input routing. |
| Feasibility spike | Small disposable experiment that proves or disproves a risky platform assumption. |
| Clean-room implementation | Original code derived from documented behavior and public specifications, not copied implementation source. |
| QUIC datagram | Unreliable, low-latency QUIC message used for replaceable pointer motion. |
| Reliable stream | Ordered QUIC channel used when loss would leave incorrect state or data. |
| SBOM | Software Bill of Materials listing release components and dependencies. |
| Provenance | Verifiable record connecting a release artifact to its source and build process. |
